      How a booked mains run works

      At the start time
      The database sends the run to the Victron GX within a minute. The GX sets its manual start timer and closes the generator relay, which switches the mains in
      At the end
      The GX opens the relay itself when the timer runs out, so the mains drops out even if nothing else happens
      Limits
      Runs cannot overlap, cannot start in the past, and are capped at 12 hours
      Missed
      A run more than 15 minutes late, or due while control is off, is skipped, never started late

      Alerts

      Checked every 2 minutes (the mains input every minute). Each one sends a phone note once its wait is over, and an all-clear when it ends. Switch off any you don't want. None of them ever switches the mains off: the GX's own rules stay in charge as the fallback.
